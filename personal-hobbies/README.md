# Personal Information and Hobbies React App

A simple React application that displays personal information and favorite hobbies using React and Bootstrap.

## Features

* Displays personal information:

  * Name
  * Age
  * Student status
* Displays favorite hobbies using a normal `for` loop.
* Displays favorite hobbies using the `map()` method.
* Includes an interactive **Show Enthusiasm** button.
* Displays the initial message:
  `Click the button to see my enthusiasm!`
* Changes the heading background color when the button is clicked.
* Displays:
  `Hello from React! I love my hobbies!`

## Technologies Used

* React
* JavaScript
* Bootstrap
* HTML
* CSS
