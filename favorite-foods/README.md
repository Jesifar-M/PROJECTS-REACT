# Favorite Foods React App

A simple React application that displays a list of favorite foods with an interactive button for each food.

## Features

* Displays a list of favorite foods.
* Provides a button next to each food.
* Shows `I love [food name]!` when a food button is clicked.
* The message updates based on the last clicked food.
* Displays the initial message:
  `Select a food that you love!`

## Technologies Used

* React
* JavaScript
* HTML
* CSS

## How to Run

   bash
npm install
npm start


Open the application in your browser at:


http://localhost:3000
