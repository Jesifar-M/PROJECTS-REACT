# Welcome Card React App

A simple React application that displays a personalized welcome message using React and Bootstrap.

## Features

* Displays a personalized welcome message.
* Uses a variable to store the user's name.
* Uses a Bootstrap card for the layout.
* Displays an internal image from the project folder.
* Displays an external image from an online URL.
* Uses Bootstrap's `img-fluid` class for responsive images.
* Internal image has a fixed width of 200px.
* Uses inline CSS for heading styling.
* Displays a description below the images.
* Includes basic console logging.

## Technologies Used

* React
* JavaScript
* Bootstrap
* HTML
* CSS

## How to Run

Install the required packages:

    bash
npm install

Start the React application:

   bash
npm start


Open the application in your browser:

   text
http://localhost:3000
