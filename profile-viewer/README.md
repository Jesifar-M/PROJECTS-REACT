# Profile Viewer

A small, responsive React profile viewer. Start in guest mode, open Alice's profile, explore her details and skills, or use the contact link to say hello.

## Features

- Guest view with a profile preview.
- Switch into Alice's profile and return to guest view.
- Profile details, skills, location, and a contact link.
- Responsive layout with keyboard-visible focus styles.
- Updates the browser tab title to match the active view.

## Run locally

From this folder, install dependencies and start the development server:

```sh
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production build

```sh
npm run build
```
